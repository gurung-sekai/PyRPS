# Review of rspy

A simple project that has helped me practice some basic Python Concepts 

Topics used

• **import** - used to import the **random** module 
• **input()** - used to get the player's choice. 
• **Variables** - used to store the player's choice and the computer's choice. 
• **List** - used to store rock, paper and scissors. 
• **random.choice.()** - used to randomly select the computer's available choices.
• **print()** - used to display information to the user.
• **F-strings** - used to include variables inside printed messages.
• **if, elif, and else** - used to decide who wins.
• **Nested if statements** - used to compare the player's choice with the computer's choice.
• **==** - used to compare values.
• **Comments** - used to explain different parts of the code.
